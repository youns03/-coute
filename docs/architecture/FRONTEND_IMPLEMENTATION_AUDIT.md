## قرار التنفيذ

ستبدأ هذه السلسلة بمرحلة مستقلة ومحدودة بعنوان **Frontend Foundation**، فوق `main` الحالي، وتشمل الخطوط والطباعة والنصوص والعرض المتجاوب وفحص الخطوط في CI. لن تعيد تنفيذ تحسينات PR #3، ولن تغيّر التنقل أو عقود ViewModel والصوت في نفس التغيير.

بعد نجاح هذه المرحلة، تُنفذ تجربة التتبع والتمرير ثم التغييرات العامة مثل mini-player والتنقل في PRs مستقلة، مع إبقاء كل مرحلة قابلة للتراجع والتحقق.
