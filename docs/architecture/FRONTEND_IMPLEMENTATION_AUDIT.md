## تحديث الصيانة والاستقرار

أضيفت في هذا التحديث إصلاحات شاملة شملت:
- دعم التراجع الصوتي الكامل لمستوى API 24 عبر `AudioFocusRequest` و`AudioManager.OnAudioFocusChangeListener` وإلغاء الحلقات غير المتزامنة دون `Thread.sleep`.
- إلغاء فوري لعملية التوليد في `PiperSherpaTtsEngine` عبر `generateWithCallback` وتنظيف `AudioChunkCache` عند بدء التطبيق.
- ترقية قاعدة البيانات إلى الإصدار 4 (`MIGRATION_3_4`) لحفظ ترجمات الفقرات بجدول `paragraph_translations`، وربط زر حفظ الفقرة في القارئ بقاموس المفردات.
- حساب التقدم الحقيقي متعدد الفصول في المكتبة وإصلاح استعادة حالة تبويب القارئ.
