# تدقيق التنفيذ المعماري والواجهة الأمامية (النسخة المحدّثة)

**الحالة الموثقة:** تطوير متكامل للبنية الخلفية والواجهة الأمامية (تطبيق فعلي دون نماذج وهمية)  
**الهدف التقني:** الانتقال بتطبيق **Écoute** من مجرد تحسينات شكلية إلى محرك محلي متماسك وموثوق في العمل دون إنترنت، مع واجهة استخدام متناغمة مستلهمة من هوية الأتيليه التحريرية.

---

## أولاً: البنية الخلفية (`Backend & Local Runtime`)

| المكون | التنفيذ الفعلي | الملفات الأساسية |
|---|---|---|
| منسّق المهام المحلي الموحد | تنسيق مركزي بأولويات (`INTERACTIVE`, `HIGH`, `NORMAL`, `BACKGROUND`) وقفل `heavyInferenceMutex` لمنع تزامن عمليات الاستنتاج الثقيلة، مع تحكم بالإيقاف/الاستئناف/الإلغاء/إعادة المحاولة | `runtime/LocalTaskCoordinator.kt` |
| حاكم الذاكرة التلقائي | مراقبة `PSS` و`availableRamMb` وتفريغ محركات الصوت (`TTS`) والتفريغ (`ASR`) الخاملة تلقائياً بعد انتهاء المهلة أو انخفاض الذاكرة (`TRIM_MEMORY_RUNNING_LOW`) دون مقاطعة التشغيل النشط | `runtime/RuntimeMemoryGovernor.kt` |
| ترقية قاعدة البيانات Room v5 | ترقية مخطط البيانات عبر `MIGRATION_4_5`: إضافة جدول `recent_activities` وحقول `mediaKind`, `coverStyleId`, `coverImagePath`, `sourceContentHash`, `fileSizeBytes`, `audioFilePath`, `audioDurationMs`, `isCompleted`, `lastPositionMs` | `data/AppEntities.kt`, `AppDaos.kt`, `AppDatabase.kt`, `data/SettingsDataStore.kt` |
| استيراد الملفات والتكرار والأغلفة | دعم OOXML `.docx` بجانب `EPUB`/`TXT`، استيراد النص المباشر، منع التكرار عبر `SHA-256`، وتقليص وتخزين صور الأغلفة محلياً في `filesDir/covers` | `data/BookImporter.kt`, `data/LibraryRepository.kt` |
| التفريغ الصوتي المحلي دون إنترنت | فك ترميز `WAV` والصيغ المضغوطة (`MP3/M4A/AAC/OGG/FLAC`) عبر `MediaExtractor + MediaCodec` إلى 16kHz أحادي، تقسيم ذكي للمقاطع الهادئة (`<=24s`)، وتشغيل `Sherpa-ONNX OfflineRecognizer` (`NeMo FastConformer` / `Canary`) | `transcription/AudioDecoder.kt`, `transcription/SpeechTranscriptionManager.kt`, `models/ModelCatalog.kt` |
| معالجة النطق والتحكم الصوتي | تحسين نطق الأرقام الرومانية في العناوين وفواصل التنفس، تقسيم الجمل الطويلة (`splitLongSpokenClauses`)، الانتقال بالفقرة، القفز `±15` ثانية، مؤقت النوم، واختيار الصوت | `domain/FrenchTextPreprocessor.kt`, `domain/SpeechTextPreprocessor.kt`, `audio/AudioPlaybackController.kt` |

## ثانياً: الواجهة الأمامية وتجربة الاستخدام (`Frontend & UX`)

| الشاشة / المكون | التحسين المنفذ |
|---|---|
| الرئيسية (`HomeScreen` — وجهة البداية) | بطاقة متابعة القراءة/الاستماع، المهام النشطة والمكتملة مع أزرار التحكم الحية من `LocalTaskCoordinator`، رف مكتبتي الأفقي، الوصول السريع، وسجل النشاط الأخير |
| المكتبة (`LibraryScreen`) | التبديل بين الشبكة التكيفية (`2-3` أعمدة عبر `BoxWithConstraints`) والقائمة، شرائح تصفية (`الكل` / `الكتب` / `الصوتيات` / `قيد التقدم` / `المكتملة` / `المترجمة`)، الفرز، وأغلفة مخصصة أو مصممة |
| الأغلفة والإضافة الموحدة (`+`) | شاشة إضافة موحدة (`QuickAddModalSheet`) لاستيراد المستندات (`TXT/EPUB/DOCX`)، التفريغ الصوتي المحلي (`WAV/MP3/M4A/...`)، أو اللصق المباشر؛ وتخصيص الغلاف عبر قوالب الأتيليه أو اختيار صورة بالالتزام بسياسة `PickVisualMedia` دون أذونات تخزين عريضة |
| المشغل المصغر والكامل | أزرار قفز `±15` ثانية، التنقل بين الفقرات، قائمة مؤقت النوم (`15/30/45/60` دقيقة أو نهاية الفصل)، منتقي الأصوات، وإحصائيات المحرك القابلة للطي |
| مدير النماذج (`ModelManagerScreen`) | تقسيم واضح إلى 3 تبويبات (`أصوات القراءة` \| `التعرف على الكلام` \| `الترجمة`) بلغة غير تقنية، مع إظهار المساحة المتبقية بالـ MB، وشريط قابل للطي لتشخيص الذاكرة وحاكم الذاكرة التلقائي |

## ثالثاً: القيود المعروفة التي تتطلب اختباراً على جهاز فعلي

- استنتاج النماذج العصبية الأصلية (`Kokoro LiteRT-LM` و`Piper/Sherpa-ONNX TTS/ASR` `.so`)، وفك ترميز الصوت المضغوط (`MP3`/`M4A`) عبر `MediaCodec`، والخرج الفعلي على سماعة الجهاز عبر `AudioTrack` تُتحقَّق جزئياً في بيئة Robolectric باستخدام بدائل اختبار (`fakes`) وتستلزم التحقق الميداني على جهاز Android حقيقي.
